# 应用更新说明

Offer Atlas 通过 GitHub Release 提供 Windows 新版本。应用每次启动后都会安静检查更新；长时间运行时每 6 小时也会再次检查。检查不会打断当前录入或云同步。

## 使用方式

1. 在页面右上角点击“应用更新”。
2. 有新版时，可先查看版本号、发布日期和本次新增、修复、优化内容。
3. 点击“下载新版本”。应用下载完成后会自动校验安装包的 SHA-256 完整性。
4. 点击“安全重启并更新”。旧版会像正常关闭程序一样，先确认 Gitee 云同步是否正在进行，以及本机是否还有待同步修改。
5. 同步完成、旧程序退出后，更新助手才会替换 exe 并自动启动新版。

下载安装包时会优先使用 GitHub Release 的直连下载线路；直连暂时不可用时才自动切换备用线路。网络不可用或 GitHub 暂时无法访问时，应用会自动重试 5 次；仍无法完成时，顶部“应用更新”会显示“检查超时”。安装包校验失败时，更新会停止并保留旧版，不会影响当前数据。可以稍后在“应用更新”中手动再次检查。

## 数据安全

更新流程只处理应用程序和 `%AppData%\OfferAtlas\updates` 中的临时安装包，不会修改以下内容：

- 本地数据库和岗位、投递记录
- 岗位附件、简历文件
- 自动镜像与完整备份
- Gitee 云同步令牌和同步配置

如果关闭时云同步失败，应用会继续保持打开并显示原因。解决网络或 Gitee 问题后再次同步，确认成功后再继续更新即可。

## 发布者约定

每个 Windows Release 需要提供名为 `OfferAtlas-windows-amd64.exe` 的安装包，并由 GitHub Release 附带 SHA-256 digest。应用会优先识别该名称，同时兼容早期的 `OfferAtlas.exe` 资产名称。
