# offer Atlas 快速上手

本文会通过一个常见的投递示例来介绍Offer Atlas的核心使用方式。

## 1. 双击exe文件，进入应用，来到总览界面

![image-20260821160015907](./assets/image-20260821160015907.png)

总览界面展示了所有投递的统计信息，并提供了**“快速收录”**功能的入口和**“待办事项”**的入口，**“待办事项“**暂时不做介绍，后面会单独介绍，**“快速收录”**是投递过程中使用最频繁的功能，在网上搜索到自己心仪的岗位，可以在这里填充对应的公司、批次、岗位信息。



## 2. 点击总览页的快速收录，收录第一个岗位

![image-20260821161121334](./assets/image-20260821161121334.png)





分别填写公司信息、批次信息（如27秋招，27春招）、岗位信息。

![image-20260821162050909](./assets/image-20260821162050909.png)





其中岗位信息支持==**ctrl + v**== 粘贴截图上传图片，这里可以上传一些==**岗位JD或者笔试安排**==的截图。

![image-20260821162621448](./assets/image-20260821162621448.png)





信息填写完成后点击**“收录岗位“**，会自动跳转到该岗位的详情页。

里面是我们刚填写的岗位信息和批次信息，以及上传的截图，岗位连接可以点击用浏览器打开，或者点击旁边的复制按钮复制完整链接。

![image-20260821163813982](./assets/image-20260821163813982.png)





点击左边菜单栏的**“岗位管理”**，可以看到我们刚才收录的岗位，因为这个岗位我们还没有创建投递信息，所以投递信息和当前流程都显示**“尚未投递”**。

![image-20260821163630871](./assets/image-20260821163630871.png)



## 3. 为岗位创建投递记录

创建投递记录的入口在**“岗位详情页”**

先点击左边菜单栏的岗位管理，进入岗位管理页面

然后点击已经创建好的岗位条目进入岗位详情

![image-20260821165241454](./assets/image-20260821165241454.png)





点击**我的投递**右上角的**创建投递**

![image-20260821165502366](./assets/image-20260821165502366.png)





填写投递信息，点击保存投递记录。

==ps: 这里暂时只支持填写简历版本，当你看到这个文件的时候应该就支持上传简历附件了，这样后面就能清晰的看到当时投递这个岗位的简历到底是怎么写的==

![image-20260821165913493](./assets/image-20260821165913493.png)





现在岗位详情和岗位管理页面中已经显示了投递信息和投递状态，**投递记录**页面也可以看到我们刚才创建的投递

后续我们就可以为该投递流程增加**笔试面试等流程节点**了

![image-20260821171158411](./assets/image-20260821171158411.png)

![image-20260821171026062](./assets/image-20260821171026062.png)

![image-20260821171428953](./assets/image-20260821171428953.png)



## 4. 为投递记录添加流程节点

在左边菜单栏点击**投递记录**进入投递记录管理页面

找到我们新建的投递记录，点击详情按钮，进入投递记录详情页

![image-20260821171758691](./assets/image-20260821171758691.png)



点击新增流程节点按钮

![image-20260821172111770](./assets/image-20260821172111770.png)



填写该流程节点的信息，点击保存流程节点

![image-20260821172235681](./assets/image-20260821172235681.png)



这里是用同样的方式创建了三个流程节点的效果

![image-20260821172433742](./assets/image-20260821172433742.png)



在**投递记录**概览界面也能看到我们创建的流程节点

==ps：显示不全的节点可以通过下方的滑动条左右拖动浏览==

![image-20260821172705950](./assets/image-20260821172705950.png)





## 5. 日历和待办功能介绍

日历和待办功能的设计主要是为了记录已经预约的笔试或者面试，所以暂时不支持自己新增待办事件，应用会自动根据投递节点中用户输入的面试时间或者笔试时间来识别哪些是待办事件。

例如，我们在**上一步**中创建了**“笔试”**、**“一面”**、**“二面”**三个流程节点，其中**“笔试”**和**“一面”**的开始时间都小于当前时间，并且状态是通过，所以日历和待办中不会显示这两个事件，但是**“二面”**节点的状态是**已预约**并且开始时间大于当前时间（当前时间是2026.8.21），所以该节点的事件**“二面”**会被自动收录到日历和待办中具体显示效果如下图：

## 6. 总览界面介绍

总览界面展示了所有投递的统计信息，并提供了**“快速收录”**功能的入口和**“待办事项”**的入口，**“待办事项“**和**“快速收录”**前面已经详细介绍过了，这里主要介绍一下统计信息的展示。

页面上记录了每个类型的进入次数、通过次数和未通过次数，核心作用是对所有投递做一个统计记录，对求职本身并没有什么帮助。

![image-20260821175108009](./assets/image-20260821175108009.png)



==ps: 上面每个统计数字都可以点击跳转到投递记录页面，并且只显示该数字对应的记录==

例如二面的进入次数一其实对应的就是我们上面创建的投递记录

![image-20260821175738014](./assets/image-20260821175738014.png)



点击该这个数字，会自动跳转到对应的投递记录，筛选条件和该数字的含义是一一对应的：

![image-20260821175925087](./assets/image-20260821175925087.png)



## 7. 数据安全介绍

本应用提供了数据一键备份功能，并可以选择自己之前的备份进行数据回滚，其中包括我们上传的截图附件等，当一次性需要做大量改动之前，可以先做一次备份。

![image-20260821180349070](./assets/image-20260821180349070.png)



此外，本应用会自动根据投递信息同步生成一个能凑活看的投递记录表格，文件可以直接用excel打开：

点击打开镜像目录

其中history中每一天会留存一个表格，该表格的数据只截止到当天最后一次修改
