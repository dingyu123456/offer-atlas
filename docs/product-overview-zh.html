核心功能

从发现机会到安全恢复的完整闭环
01 / 总览

投递总览

一打开就能看到总投递、进行中、已通过、未通过，以及笔试、测评和各轮面试的情况。快速收录和待办提醒也都在这里。

想看哪一类，就直接点进去查看对应投递，不用再自己翻表格。
投递状态统计笔试与测评面试分轮统计待办提醒
02 / 机会归档

公司、批次与岗位管理

把公司、招聘批次和岗位分开管理：公告与时间、岗位编号和地点、优先级与链接各自清楚，后续查找不会混乱。

岗位 JD、官网页面、群通知等截图和文件，都可以集中收在岗位详情里。
公司 → 批次 → 岗位招聘公告截图与附件优先级
03 / 快速收录

把“看到机会”快速放进系统

看到新机会时，一次填写公司、招聘批次和岗位即可收录。已有的公司或批次可以直接选用，信息不完整也能先记下来，之后再补。

复制一张 JD 截图，直接粘贴进来；上传后马上能看到缩略图，确认无误再保存。
一次收录直接选用已有信息粘贴截图缩略预览
04 / 投递推进

投递记录与动态流程

所有已投递岗位集中在一张清晰的列表中，可按进展、环节和结果筛选，也可以按优先级或投递时间排序。进入详情就能查看并更新完整过程。

每家公司要几轮，就记录几轮。流程会随着你的真实进展自然延长，投递状态也会同步更新。
统一投递列表组合筛选节点可排序状态自动联动
05 / 时间安排

日历与待办执行视图

为笔试、面试或结果通知填好时间，它们就会出现在日历和待办里。周视图和月视图帮助安排时间；今天、未来 7 天、逾期和等待结果则帮助聚焦下一步。

时间只需填写一次。日历和待办会同步提醒，点开就能回到对应投递。
周 / 月日历结果提醒等待结果回到投递
06 / 数据安全

安全镜像、完整备份与恢复

投递信息保存在本机。日常可以直接打开安全镜像查看；在大批量修改前，也可以创建一份完整备份，把岗位附件一并保存。

平时看镜像，出现误操作时用完整备份恢复。恢复前会先保留当前数据，更安心。
本机保存可直接查看附件一并备份安全恢复
全局搜索贯穿整个记录库在顶部直接检索公司、招聘批次、岗位名称、岗位编号，同时查看匹配的岗位与投递记录。

从招聘信息到个人实际进展
公司信息公司行业、官网与备注
招聘活动招聘批次公告、时间与流程参考
目标岗位岗位JD、优先级、链接与截图
我的投递投递记录日期、渠道与简历版本
每一步进展流程节点按通知逐步补充

关系很简单：一个招聘批次可以包含多个岗位；一个岗位通常对应一条投递；一条投递可以逐步补充多个流程节点。
